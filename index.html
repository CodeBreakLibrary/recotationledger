One-time setup (do this once per Sheet)
  1. Open the Google Sheet you want to use
  2. Menu: Extensions → Apps Script
  3. Delete anything in the editor, then tap "Copy setup code" below and paste it in
  4. Tap the Deploy button (top right) → New deployment
  5. Click the gear next to "Select type" → choose Web app
  6. Set "Who has access" to Anyone, then Deploy
  7. Approve the permissions prompt (it's your own script on your own Sheet)
  8. Copy the Web app URL it gives you and paste it below
